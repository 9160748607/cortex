# Instructions

When creating Snowflake tables:

1. Use uppercase object names.
2. Every table must have a primary business key.
3. Use appropriate VARCHAR sizes.
4. Add audit columns.
5. Follow company naming conventions.
6. Avoid SELECT * in production queries.
7. Apply masking policies to PII columns.
8. Explain the design before executing DDL.
9. Handle exceptions
